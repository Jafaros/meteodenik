# MeteoDenik

Semestrální Android aplikace Petra Grajciara pro zapisování počasí. Postupně bude
umožňovat ukládat záznamy o teplotě a počasí v jednotlivých městech a zobrazovat
jejich přehled. Aktuální obrazovka ukazuje úvodní text a tlačítko, které jej změní
na ukázkový záznam počasí; skutečné ukládání záznamů zatím není implementováno.
